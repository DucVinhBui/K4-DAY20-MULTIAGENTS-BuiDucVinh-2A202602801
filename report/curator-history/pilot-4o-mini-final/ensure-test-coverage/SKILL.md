---
name: ensure-test-coverage
description: Use when developing code to ensure comprehensive testing and validation of functionality.
---
1. Create unit tests for every public function, ensuring that edge cases and typical use cases are covered.
2. Implement regression tests for any bugs that have been fixed, ensuring that they do not reoccur.
3. Organize tests in a dedicated test directory, following naming conventions for test files and functions.
4. Ensure that all tests are runnable and that the test suite passes before finalizing any changes.
5. Document the purpose of each test clearly in comments to facilitate understanding and maintenance.
6. Self-check: Run the test suite and confirm that all tests pass without errors before submission.
