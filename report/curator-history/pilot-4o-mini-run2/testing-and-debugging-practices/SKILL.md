---
name: testing-and-debugging-practices
description: Use when implementing tests and debugging code to ensure reliability and maintainability.
---
1. Write unit tests for every function, ensuring coverage for edge cases and expected behavior.
2. Use descriptive names for test functions to clearly indicate what is being tested.
3. Run tests frequently during development to catch issues early.
4. Implement regression tests for any bugs fixed, ensuring they do not reoccur.
5. Use a consistent testing framework and adhere to its conventions for structuring tests.
6. Document test cases and expected outcomes for clarity and future reference.
7. Review and refactor tests regularly to maintain code quality and relevance.
8. Ensure that all tests pass before finalizing any changes to the codebase.
