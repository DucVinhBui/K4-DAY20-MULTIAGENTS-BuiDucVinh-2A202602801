---
name: validate-output-format
description: Use when generating output files to ensure compliance with specified formats and conventions.
---
1. Review the output file format requirements as specified in the project documentation.
2. Ensure that all required fields are present in the output file.
3. Validate that data types and formats (e.g., date formats, currency representations) match the specifications.
4. Check for any additional rules, such as naming conventions or sorting requirements.
5. If using JSON, ensure that the structure adheres to the expected schema.
6. Conduct a self-check: confirm that the output file meets all specified requirements before submission.
