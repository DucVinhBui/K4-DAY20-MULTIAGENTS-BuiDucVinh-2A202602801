---
name: check-and-annotate-code
description: Use when preparing code for public functions to ensure clarity and maintainability.
---
1. Review all public functions (names not starting with '_') in your code.
2. Ensure that each function has type annotations for all parameters and the return value.
3. Check that the function docstrings clearly describe the purpose, parameters, and return values.
4. Validate that the function adheres to its docstring specifications by running relevant tests.
5. If any discrepancies are found, update the code or the docstring accordingly.
6. Conduct a self-check: confirm that all public functions are properly annotated and documented.
