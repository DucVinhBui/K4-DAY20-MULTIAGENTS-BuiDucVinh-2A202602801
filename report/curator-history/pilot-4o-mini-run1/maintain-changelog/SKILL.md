---
name: maintain-changelog
description: Use when making changes to code to ensure proper documentation of modifications.
---
1. Open the `CHANGELOG.md` file in your project.
2. Under the heading '## Unreleased', add a bullet point for each fix or feature added.
3. Format each bullet as follows: `- fix(<function name>): <short description>`.
4. Ensure that you have at least three entries for significant changes or bug fixes.
5. Review the changelog for clarity and completeness.
6. Conduct a self-check: confirm that all recent changes are documented in the changelog.
